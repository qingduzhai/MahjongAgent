## 2. 子页规格

### 2.1 总览

- 记忆分层示意(只读图解):瞬时视觉(内存,不持久化)/ 本局工作记忆(GameEvent 溯源)/ 情景记忆(Episode)/ 语义记忆(已验证长期事实)/ 程序记忆(代码发布,Agent 无权在线修改);
- 各类语义记忆计数:窗口视觉映射、已验证战术模式、对手行为统计、用户提示偏好、典型牌局;
- 待办列表:待审核 candidate、记忆冲突、队列失败重试项——每项可点击直达对应子页。

### 2.2 版本与发布

| 行 | 内容 |
|---|---|
| 策略版本 | `0.1.0`(当前)· 影子策略 `0.2.0-cand` 评测中(固定评测集进度 62%) |

### 2.3 记忆检索(MemorySearch)

```text
┌─ 检索 ──────────────────────────────────────────────────────────┐
│ 规则集 [wuhan-koukoufan ▾] 巡目 [8] 向听 [1] 癞子 [1] 开口 [2]  │
│ 对手模式 [疑似清一色 ▾]  文本 [对家疑似清一色时如何兼顾牌效____] │
│ [检索]                                                           │
│ ── 结果(带命中理由)────────────────────────────────────────── │
│ ▸ Episode #0831 · 同档案第3局第9巡   综合 0.87                  │
│   结构相似 0.91 · 语义 0.78 · 关键词 0.66 · 时效 1.0 · 质量 0.9  │
│   当时建议 打9s · 实际 打7z · [查看该巡复盘]                    │
│ ▸ Episode #0402 · …                                            │
└──────────────────────────────────────────────────────────────────┘
```

- 结构化条件为主(规则集精确过滤 → 阶段/结构特征 → 向听/癞子/开口/对手模式),文本检索为辅(FTS5/语义);**牌局结构相似度优先于自然语言相似度**(backend §9);
- 每条结果必须展示**命中理由**:分项得分(domain/semantic/keyword/relation/temporal/quality − 冲突/低置信惩罚),不允许只给一个无解释的相关度。

### 2.5 待审核(MemoryReview)

candidate 记忆审核队列(复核 backend 三态 + superseded):

| 列 | 说明 |
|---|---|
| 内容 | 候选经验摘要(如"对家连续摸后即打时筒子中张危险上调") |
| 来源 | 溯源链:Episode → GameEvent ID 列表(可点开) |
| 适用范围 | 适用 RuleProfile + 有效时间 valid_from/valid_to |
| 验证 | 规则验证 ✓/✗ · 策略回放结论 · 固定评测集结果 |
| 操作 | [确认→confirmed] [拒绝→rejected](均写审计记录;拒绝需选原因) |

冲突项并排对照(旧 confirmed vs 新 candidate),确认新项时旧项自动转 `superseded`,版本链保留,可回滚。

### 2.6 情景记忆(Episodes)

按局浏览 Episode 列表:局/巡、特征(向听、有效进张、癞子数、开口数、下家吃牌风险)、建议 vs 实际动作、策略版本;固定提示 `Episode 是经历,不自动代表正确经验;单局输赢不作为策略标签`;[查看该巡复盘] 跳 09 号文件页。

### 2.7 后台学习队列

`consolidation_jobs` 列表:触发原因(局后/空闲/累积/冲突/手动)、状态(排队/运行/完成/失败重试)、产出(candidate 数、冲突数);任务幂等可重试(backend §15);[立即整理] 手动触发(空闲时执行,不阻塞牌局提示)。

### 2.8 体检与维护(危险区)

- 去重(相似记忆合并预览 → 确认)、记忆体检(失效/低质量/过期项清单)、按 namespace 删除、版本回滚;
- 全部 Danger 操作:二次确认 + 影响范围清单 + 审计记录;confirmed 记忆删除不级联删除原始 Episode 与 GameEvent。

## 3. 与全局的关系

- 详细策略面板"参考经验"(05 §3 ④)与本页 `检索审计` 详情一一对应(#231 示例);复盘页(09)Episode 与本页 `情景记忆` 同源;
- 本页所有记忆条目必含:来源、适用范围(RuleProfile)、有效时间、可信度、版本(backend §8.3 MemoryRecord 字段);
- 自动形成 candidate 的范围与禁止自动晋升的范围(backend §12)在本页"总览"以只读说明呈现;程序记忆(规则/牌效算法/策略权重/提示模板)经 Git 发布,UI 永远只读。

## 4. 状态覆盖

| 状态 | 呈现 |
|---|---|
| 空(新装机,无记忆) | 空态:`还没有长期记忆 · 完成牌局后自动开始积累` + 分层图解 |
| 整合中 | 卡带显示 `后台整合中…`(静态,不打断浏览);队列子页进度条 |
| 待审核积压 | 子导航计数徽标;卡带 candidate 转 Warning |
| 冲突 | 待审核子页置顶冲突区,Danger chip + 对照视图 |
| 无网络 | **本地记忆全部可用**(检索/审核/维护不受影响);仅 Embedding/LLM 提炼类后台任务排队等待,注明原因 |
| 删除确认 | 模态列出范围与不可恢复项,输入命名空间确认 |
