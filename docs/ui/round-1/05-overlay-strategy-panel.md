# 05 悬浮助手 · 详细策略面板(高保真稿)

> 对应提示词 v2 第五节 3。420×520,从目标窗口侧边(默认右侧,避开手牌区)滑出;`Alt+M` 呼出/收起,焦点离开自动收起。定位:**给愿意多花 10 秒的用户一张"为什么"的完整答卷**,但不替代主窗口的诊断深度。

## 2. 分区规格

| 分区 | 高 | 规格 |
|---|---|---|
| 标题栏 | 40 | 左:返回箭头(回紧凑卡)+ 局面摘要 Body.Strong(`第6巡 · 轮到自家 · 一向听`);右:`识别 96%` Caption、`牌效计算` chip(Info.Subtle 底,表确定性来源)、`✕`(Esc/Alt+M) |
| 推荐 hero | 88 | Tile.L 推荐态 + `建议打 九条`(Caption+Title)+ 理由 ≤ 2 行 Body 13 `Text.Secondary`;`为什么? ▸` 链接色,展开 §4 解释抽屉 |
| 备选动作 | 96 | 2–3 行,每行:Tile.M + 动作 + 三列差异(`进张 -4 张` `收益` `风险`,与推荐项的**相对**差异,负收益用 `Text.Tertiary`,风险升降用 ▲▼ 图标 + 文字);底部 `ⓘ 癞子(六筒)不可打出` 规则提示 Caption |
| 有效进张 | 44 | 标题 `有效进张 12 张` + Tile.S 横排(≤ 9 枚,超出 `+3` 折叠 chip);癞子/皮在进张条中带角标 |
| 特殊牌行 | 48 | 两行 Caption→Body:癞/皮/翻(各带 M 以下小牌或文字角标)+ 开口次数、当前翻数;红中杠状态单独第二行 |
| 对手风险 | 96 | 三家各一行:开口数、危险度(图标 + 文字档)、一句依据(≤ 18 字,必须标注推测属性);分区标题右侧固定 `(依据均为启发式推测)` Caption `Text.Tertiary` |
| 最近关键事件 | 72 | ≤ 3 行,`巡目 + 行为 + 牌`,Tile.S 内嵌;更多 → "查看完整事件流"跳主窗口当前牌局页 |
| 不确定信息条 | 32 | 仅存在低置信度观察时出现;`Brush.Warning.Subtle` 底,列出不项定与 `[✎ 纠正识别]` 按钮(进纠错弹窗) |
| 底栏 | 32 | 左:`为什么这样建议 ▸`;右:`收起 Alt+M` Caption `Text.Tertiary` |

## 3. 备选动作差异列口径

三列差异全部相对推荐项计算并标注来源:

- **牌效差异**:`进张 -4 张`、`退向听` —— 规则引擎确定性计算,直接陈述;
- **收益**:`损失筒子扩展`、`保留三色可能` —— 策略特征短语,≤ 8 字;
- **风险**:`放铳风险较低/中/较高 ▼▲` —— 启发式,带档文字;信息不足写 `信息不足`,不猜档。

## 4. "为什么"解释抽屉(展开 +160,面板变 420×680 或内部滚动)

点 `为什么这样建议 ▸` 在推荐 hero 下方展开,内容三层(与审核清单"区分确定事实/模型推测/低置信度"对应):

```text

│ ① 确定事实:你 13+1 张,当前一向听;九条不与任何对子/搭子 │
│    相连(已见九条 1 张,八条已见 2 张)。                  │
│ ② 规则计算:打九条后有效进张 12 张(一万/四万/七万/二筒/  │
│    五筒/八条…);打次优白板仅 8 张。                        │
│ ③ 推测判断:下家疑似听筒子(依据:连续 3 巡摸后即打),    │
│    九条属条子,相对更稳妥 —— 推测,置信中。              │
│ 规则依据:二五八将 · 癞子不可打出 · 口口翻(开口×1=1 翻) │

```

## 5. 全部状态

| 状态 | 呈现 |
|---|---|
| 正常 | 如 §1 |
| 低置信度 | 推荐 hero 牌改虚线琥珀描边;标题栏追加 `▲ 识别置信度偏低`;不确定信息条必出现 |
| 信息不足 | hero 区替换为"信息不足,暂不提供强建议 + 缺失项清单";备选/进张区灰显禁用 |
| 识别中/恢复中 | 面板顶部 24px Info 条 `正在重新识别牌桌…`,内容区显示上一次快照 + `Text.Tertiary` 时间戳 `数据截至 3 秒前` |
| API 超时 | 顶部 Warning 条 `策略更新延迟,以下为最近一次计算结果`;不重试阻塞 UI |
| 窗口丢失/暂停 | 面板不出现;若已展开则收起并让胶囊进入对应状态(03 号文件 §3.6/§3.7) |
| 空(无建议历史) | 仅标题栏 + `暂无建议:尚未轮到你或本巡无需决策` + 底栏 |

## 6. 交互规格

- 滑入:自目标窗口右缘 `Motion.Panel` 280ms `Ease.Out`;滑出 200ms `Ease.InOut`;
- 收起:再按 `Alt+M`、`Esc`、点击面板外、失去可交互态超过 2s;
- 滚动:内容超出时仅中部(备选→事件)区垂直滚动,标题栏与底栏固定;
- 键盘:`↑↓` 在推荐/备选行间移动焦点,`Enter` 展开该行动机理解释,`W` 展开为什么,`C` 进入纠错,`Esc` 收起;
- 与紧凑卡互斥;面板展开期间紧凑卡不自动弹。

## 7. WPF 映射要点

`Border(CornerRadius=12) > Grid(行:40/*自适应内容/1/32)`,内容区 `ScrollViewer > StackPanel` 分 6 个 `ContentControl` 分区(各绑定只读 ViewModel 属性);对手风险与事件为 `ItemsControl`;进张条为横向 `ItemsControl`(Tile.S);解释抽屉为 `Expander` 自定义模板。滑入动画用 `TranslateTransform`,窗口本身不参与游戏窗口的激活链。
