# 04 悬浮助手 · 紧凑建议卡(高保真稿)

> 对应提示词 v2 第五节 2。轮到用户或出现重要风险时自动出现,默认 6 秒后自动收起(可配 3–15s),不抢焦点。

## 1. 正常态(360×160)

```text
x=0                                                        x=360
┌────────────────────────────────────────────────────────┐ y=0
│ 建议打                                          94%    │ 0–28   标题行
│ ┌──────┐   九条                                        │ 28–92  主区
│ │      │   一向听 · 有效进张 12 张                     │
│ │ 九条 │   上家风险:中 ▲                              │
│ │ (L)  │                                               │
│ └──────┘                                               │
│ ────────────────────────────────────────────────────── │
│ ⌨Alt+M 详细策略    识别96% · 牌效计算      6s ▸▶ 收起 │ 124–160 底部条
└────────────────────────────────────────────────────────┘ y=160
```

| 区域 | 位置 | 内容与规格 |
|---|---|---|
| 标题行 | x16 y8,高 20 | 左:`建议打` Caption 11 `Brush.Text.Secondary`;右:`94%` Display 小号数字(Font.Numeric 20 SemiBold)`Brush.Brand.Default` = 推荐置信度(牌效计算确定时的"推荐强度"评分,见 §5 措辞说明) |
| 推荐牌 | x16 y32,Tile.L 40×56 | 推荐状态(绿描边 + "荐"角标);牌名`九条` Title 20 `Brush.Text.Primary` 置于牌右 x68 |
| 状态两行 | x120 起 | 行1 Body.Strong 13:`一向听 · 有效进张 12 张`,进张数 Font.Numeric;行2 Body 13:`上家风险:中` + 风险图标(盾+两格刻度,`Brush.Warning.Default`);风险档必带文字"中" |
| 底部分隔 | y124 | 1px `Brush.Divider` |
| 底部条 | x16 y132,高 20 | 左:快捷键 chip `⌨ Alt+M` + `详细策略` Caption;中:`识别 96% · 牌效计算`(两个置信度来源,见 §5)Caption `Brush.Text.Tertiary`;右:收起倒计时 `6s` + 进度细条(宽 40 高 2,`Brush.Brand.Default` 剩余比例) |

出现方式:从胶囊位置展开(`Motion.Standard` 200ms,`Motion.Ease.Out`),避开游戏手牌/按钮区(默认从胶囊向窗口内侧展开)。

## 2. 低置信度态(识别不确定,建议降级为"倾向")

```text
┌────────────────────────────────────────────────────────┐
│ ▲ 识别置信度偏低 61% — 以下为倾向性建议,请留意        │ 顶部警示条 高24
│ 倾向打                                        71%      │
│ ┌ - - - ┐   九条                                       │
│ │  九条 │   可能仍是一向听 · 进张估算 10–14 张         │
│ └ - - - ┘   上家风险:中 ▲                              │
│ ────────────────────────────────────────────────────── │
│ ⌨Alt+M 详情    ✎ 纠正识别        手牌有1张不确定(九筒)│
└────────────────────────────────────────────────────────┘
```

与正常态的差异:

1. 顶部插入 24px 警示条:`Brush.Warning.Subtle` 底 + 三角图标 + Caption `Brush.Warning.Default`,文字说明**为什么**降级(`识别置信度偏低 61%`);
2. `建议打` 改为 `倾向打`,推荐强度改用 `Brush.Warning.Default`;
3. 推荐牌改为**低置信度牌状态**(琥珀虚线描边 + `?`角标);
4. 进张改为区间 `10–14 张`(不确定时给区间,不给伪精确值);
5. 底部出现 `✎ 纠正识别` 入口与不确定项摘要(`手牌有1张不确定(九筒)`),点击进入纠错弹窗(见 08 号文件 §4);**纠错不阻塞**:6s 后卡片照常收起。

## 3. 信息不足态(暂不提供强建议)

```text
┌────────────────────────────────────────────────────────┐
│ 信息不足,暂不提供强建议                                │
│ 第1巡 · 手牌识别完成度 9/13 · 继续观察中                │
│ ────────────────────────────────────────────────────── │
│ ⌨Alt+M 查看当前理解                          6s ▸▶ 收起│
└────────────────────────────────────────────────────────┘
```

- 不出现推荐牌,不给"伪建议";主区说明缺什么(`手牌识别完成度 9/13`);
- 用于局初、恢复后、关键区域被遮挡等场景。

## 4. 风险主动提醒态(非自家回合,出现重要风险)

```text
┌────────────────────────────────────────────────────────┐
│ ▲ 风险提醒                                              │
│ 上家疑似听牌(推测):连续 3 巡摸后即打                   │
│ 弃牌避开门类:筒子中张                                 │
│ ────────────────────────────────────────────────────── │
│ ⌨Alt+M 防守详情                                4s ▸▶ 收起│
└────────────────────────────────────────────────────────┘
```

- 触发条件由策略引擎给出(进入高风险/海底等,见架构第 7 节触发器);
- 措辞必须带"推测"标记与依据(连续 3 巡摸后即打);
- 收起更快(默认 4s),避免干扰他人回合的观战。

## 5. 置信度与措辞规范(审核重点)

紧凑卡同时出现两种"置信"信息,必须分开标注、不得合并成一个百分比:

| 信息 | 含义 | 呈现 |
|---|---|---|
| 识别置信度 | 多模态观察经校验后的可信程度 | `识别 96%`,低时进入 §2 流程 |
| 推荐强度 | 策略引擎候选动作评分的归一化表达;牌效/向听/进张为**确定性计算**,风险为**启发式推测** | `94%`(标题行)+ 底部 `牌效计算` 标注;风险行永远带"推测依据"或"启发式"字样(详细面板展开) |

禁用措辞:`稳赢` `必胜` `绝对安全` `一定不会放炮`。风险档文案固定三档:`较低` / `中` / `较高`,辅以"信息不足"。

## 6. 交互规格

| 行为 | 规格 |
|---|---|
| 自动出现 | `phase=self_turn`(轮到自家)或风险触发器;同一巡不重复弹出(收起后本巡不再自动弹,除非状态变化) |
| 自动收起 | 默认 6s(设置 3–15s);指针进入卡片(可交互态)暂停倒计时;用户完成出牌后立即收起 |
| 手动收起 | 可交互态点击卡片外 / `Esc` / 再按 `Alt+M` |
| 展开详情 | `Alt+M` 或点击卡片 → 详细策略面板(05 号文件) |
| 位置 | 吸附胶囊,向游戏窗口内侧展开;若胶囊贴右缘则向左展开,保证 360×160 完整落在窗口内 |
| 堆叠 | 与详细面板互斥(面板展开时卡片收起);异常状态条不遮挡游戏操作区 |

## 7. WPF 映射要点

`Border(CornerRadius=12) > Grid(行:28/96/1/35)`;推荐牌为独立 `TileView` 控件(状态依赖属性);倒计时用底部 2px `ProgressBar`(IsIndeterminate=False,绑定剩余秒);展开动画用 `RenderTransform.ScaleY`+`Opacity`,从不使用布局重排动画。
