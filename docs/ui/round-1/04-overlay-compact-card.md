# 04 悬浮助手 · 紧凑建议卡(高保真稿)

> 对应提示词 v2 第五节 2。轮到用户或出现重要风险时自动出现,默认 6 秒后自动收起(可配 3–15s),不抢焦点。
> **v1.1 修订**(按 `review-codex.md`):P0-2 删除"推荐 94%"式伪概率,改为推荐等级与相对差异;P1-1 低置信度按策略敏感性二分(关键→暂停建议,非关键→保留建议+影响范围);P1-4 修正警示条高度;P0-3 交互归入 Passive/Interactive 双模式。

## 1. 正常态(360×160)

```text
x=0                                                        x=360
┌────────────────────────────────────────────────────────┐ y=0
│ 建议打                                     [推荐等级 高]│ 0–28   标题行
│ ┌──────┐   九条 · 首选                                 │ 28–124 主区
│ │      │   一向听 · 有效进张 12 张                     │
│ │ 九条 │   相比次选:有效进张 +4                        │
│ │ (L)  │   上家风险:中 ▲(推测)                       │
│ └──────┘                                               │
│ ────────────────────────────────────────────────────── │
│ ⌨详细策略    识别可信度 96% · 牌效计算     6s ▸▶ 收起  │ 124–160 底部条
└────────────────────────────────────────────────────────┘ y=160
```

| 区域 | 位置 | 内容与规格 |
|---|---|---|
| 标题行 | x16 y8,高 20 | 左:`建议打` Caption 11 `Text.Secondary`;右:`推荐等级 高` chip(Brand.Subtle 底 + Brand 文字,Micro 10)——等级为候选动作相对排序的**分级表达**(高/中/低),**不是概率** |
| 推荐牌 | x16 y32,Tile.L 40×56 | 推荐状态(绿描边+"荐"角标);牌名 `九条` Title 20 + `首选` Caption `Brand.Default` |
| 状态三行 | x120 起 | 行1 Body.Strong:`一向听 · 有效进张 12 张`(Font.Numeric);行2 Body 13:`相比次选:有效进张 +4`(与次优动作的**确定性计算差值**);行3:`上家风险:中 ▲` + `(推测)` Caption——风险档必带文字与图标 |
| 底部分隔 | y124 | 1px `Divider` |
| 底部条 | x16 y132,高 20 | 左:快捷键 chip `⌨` + `详细策略` Caption;中:`识别可信度 96% · 牌效计算`(两个不同来源,见 §5)`Text.Tertiary`;右:收起倒计时 `6s` + 2px 进度细条 |

出现方式:从胶囊位置向窗口内侧展开(`Motion.Standard`,`Ease.Out`),避开手牌/按钮区;纯展示,出现在 PassiveOverlay 下,不需要任何指针输入。

## 2. 低置信度:按策略敏感性二分(P1-1)

系统先判断不确定项是否影响合法动作、向听数、癞子身份或首选弃牌(策略敏感性分析),再决定卡片形态。

### 2.1 非关键不确定 → 保留建议 + 明确标注(360×184)

```text
┌────────────────────────────────────────────────────────┐
│ ▲ 非关键不确定:手牌九筒 61% — 不影响首选弃牌(经敏感性 │ +24 警示条
│   分析);影响范围:进张估算 10–14 张                     │
│ 建议打                                     [推荐等级 高]│
│ ┌──────┐   九条 · 首选                                 │
│ │ 九条 │   可能仍是一向听 · 有效进张 10–14 张          │
│ └──────┘   上家风险:中 ▲(推测)                        │
│ ────────────────────────────────────────────────────── │
│ ⌨详细策略   ✎纠正识别    识别可信度 96%    6s ▸▶ 收起  │
└────────────────────────────────────────────────────────┘
```

- 顶部 **+24px 警示条,整卡高度变 184**(不再套用 160 布局,P1-4);`Warning.Subtle` 底 + 三角图标 + Caption `Warning.Default`;
- 警示文案三要素:不确定项(`九筒 61%`)+ 敏感性结论(`不影响首选弃牌`)+ 影响范围(`进张估算 10–14 张`,给区间不给伪精确值);
- 底部追加 `✎ 纠正识别` 入口(InteractiveOverlay 内可用);纠错不阻塞,卡片照常收起。

### 2.2 关键不确定 → 暂停建议(360×160)

```text
┌────────────────────────────────────────────────────────┐
│ ▲ 关键信息不确定,暂停建议                              │
│ 癞子身份未确认(翻牌区识别置信度 52%)                   │
│ 该不确定项影响合法动作与首选弃牌,给出建议可能误导。     │
│ ────────────────────────────────────────────────────── │
│ ✎ 纠正识别      ⌨查看当前理解                静态不收起 │
└────────────────────────────────────────────────────────┘
```

- **不出现推荐牌、不给等级**;说明缺什么、为什么停(`影响合法动作与首选弃牌`);
- 动作仅两个:纠正识别 / 查看当前理解(详细面板空建议态);
- 卡片**不自动收起**,但保持静态、不闪烁、不遮挡操作区;识别恢复或被纠正后自动撤销。

## 3. 信息不足态(暂不提供强建议,360×160)

```text
┌────────────────────────────────────────────────────────┐
│ 信息不足,暂不提供强建议                                │
│ 第1巡 · 手牌识别完成度 9/13 · 继续观察中                │
│ ────────────────────────────────────────────────────── │
│ ⌨查看当前理解                                  6s ▸▶ 收起│
└────────────────────────────────────────────────────────┘
```

用于局初、恢复后、关键区域被遮挡;不出现推荐位。

## 4. 风险主动提醒态(非自家回合,360×160)

```text
┌────────────────────────────────────────────────────────┐
│ ▲ 风险提醒                                              │
│ 下家疑似听牌(推测):连续 3 巡摸后即打                   │
│ 弃牌避开门类:筒子中张                                 │
│ ────────────────────────────────────────────────────── │
│ ⌨防守详情                                        4s ▸▶ 收起│
└────────────────────────────────────────────────────────┘
```

- 触发由后端 `AlertPolicy` 给出(对手牌型倾向、疑似听牌、承包风险、下家吃牌风险显著变化;backend-agent-memory §14);普通对手动作只更新胶囊信息条,不弹卡;
- 措辞必带"推测"与依据;对手信息只表述为倾向与风险,不表述为确定事实;
- 默认 4s 收起。

## 5. 可信度与措辞规范(审核重点)

卡片上同时出现的两类信息必须分开标注、不得合并:

| 信息 | 含义 | 呈现 |
|---|---|---|
| 识别可信度 | 多模态观察经校验后的可信程度 | `识别可信度 96%`;低时进入 §2 流程 |
| 推荐等级 | 策略候选动作**相对排序**的分级(高/中/低);向听、进张为规则引擎确定性计算,风险为启发式推测 | `推荐等级 高` chip + `相比次选:有效进张 +4`(确定性差值)+ 底部 `牌效计算` 标注 |

**禁止**把候选归一化分数显示为百分比(它不是胜率、正确率或置信概率,review P0-2)。未来若有经校准的胜率/放铳率模型,才可显示百分比,并须注明模型、样本与误差范围。
禁用措辞:`稳赢` `必胜` `绝对安全` `一定不会放炮`。风险档固定:`较低`/`中`/`较高`,辅以`信息不足`。

## 6. 交互规格(双模式)

| 行为 | 规格 |
|---|---|
| 自动出现 | PassiveOverlay 下纯展示:自家回合(策略引擎 `SelfTurnDetected`)或 `AlertPolicy` 风险触发;同一巡不重复弹出(收起后本巡不再自动弹,除非状态变化) |
| 自动收起 | 默认 6s(可配 3–15s);**确认用户出牌事件后立即收起,10s 兜底**(review 决定 #9);关键不确定暂停卡(§2.2)不自动收起 |
| 进入交互 | 全局热键(可配置,Mock 占位 `Alt+M`)→ InteractiveOverlay:卡片停止倒计时、可点击展开详细面板、可进纠错;无操作 30s 回被动 |
| 手动收起 | InteractiveOverlay 内:`Esc` / 点击卡片外 / 再按热键;PassiveOverlay 下不存在指针收起(穿透) |
| 位置 | 吸附胶囊向窗口内侧展开;胶囊贴右缘则向左展开,保证整卡(含 184 变体)落在窗口内安全区 |
| 堆叠 | 与详细面板互斥;异常条不遮挡游戏操作区;`Esc`/方向键只在 InteractiveOverlay 获得焦点后有效 |

## 7. WPF 映射要点

`OverlayHostWindow` 内紧凑卡模板:`Border(CornerRadius=12) > Grid(行:auto警示条/28/96/1/35)`——警示条行高随内容,卡片总高 160/184 由内容决定,不写死(P1-4);倒计时为底部 2px `ProgressBar`(绑定剩余秒);出现/收起动画用 `RenderTransform` + `Opacity`,不做布局重排动画。
