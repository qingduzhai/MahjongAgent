# 02 视觉方向与设计 Token

> 对应提示词 v2 第三、四节。所有 Token 给出 ResourceDictionary 键名建议,落地映射见 [12-wpf-mapping.md](12-wpf-mapping.md)。后续所有稿件只引用 Token 键名,不写死色值。

## 1. 视觉方向

**气质:专业、冷静、可信、低干扰的实时分析工具。**

- 深石墨底色托底,信息层次靠"明度台阶"而非彩色分区;
- 玉石绿只做一件事:标记"系统当前推荐/当前焦点",不铺大面积;
- 麻将牌是全套界面里唯一的"实体物件":象牙白、带细边和微投影,营造"数字牌桌"质感;
- 琥珀 = 需要注意(低置信度、风险提示、待确认);红 = 仅高风险或错误,小面积;
- 任何状态都同时用文字 + 图标 + 颜色表达,颜色永不单独承担语义;
- 明确排除:金币/筹码/赌场灯效、大面积红金、霓虹电竞、卡通吉祥物、"稳赢/必胜/绝对安全"措辞。

### 两套色系的边界(重要)

界面中存在两类颜色,审核时请勿混淆:

1. **系统状态色**:品牌绿/成功绿/琥珀/危险红/信息蓝,表达界面状态与风险;
2. **牌面固有色**:麻将牌面上的墨色(万=赭红、条=竹绿、筒=黛蓝、中=朱砂等),是"牌的内容",不表达状态。牌的**状态**(推荐/危险/低置信度/选中)一律用系统状态色的描边与文字角标表达,与牌面墨色分离。

## 4. 间距 / 圆角 / 阴影

间距体系(4 基数):`Space.1=4` `Space.2=8` `Space.3=12` `Space.4=16` `Space.5=24` `Space.6=32` `Space.7=48`(仅页面级分区)。

| Token 键 | 值 | 用途 |
|---|---|---|
| `Radius.Tile` | 3 | 麻将牌 |
| `Radius.Control` | 4 | 按钮、输入框、下拉 |
| `Radius.Chip` | 4 | 标签/徽标 |
| `Radius.Card` | 8 | 卡片 |
| `Radius.Panel` | 12 | 弹窗、详细策略面板、浮层 |
| `Radius.Capsule` | 999 | 待机胶囊、状态 pill |

| Token 键 | WPF 对应(DropShadowEffect) | 用途 |
|---|---|---|
| `Shadow.Card` | BlurRadius 4,ShadowDepth 1,Opacity 25%,Color `#000` | 卡片 |
| `Shadow.Overlay` | BlurRadius 16,ShadowDepth 4,Opacity 35%,Color `#000` | 悬浮助手、浮层 |
| `Shadow.Dialog` | BlurRadius 32,ShadowDepth 8,Opacity 45%,Color `#000` | 模态弹窗 |

## 5. 麻将牌尺寸(三档)

| 档位 | 尺寸(px) | 牌面字号 | 用途 |
|---|---|---|---|
| `Tile.S` | 20×28 | 11 | 弃牌河、已见牌统计、有效进张条、事件流内嵌 |
| `Tile.M` | 28×40 | 16 | 副露、备选动作、纠错候选、复盘 |
| `Tile.L` | 40×56 | 24 | 自家手牌、推荐弃牌 hero、紧凑建议卡 |

- 宽高比固定 5:7;横置牌(吃碰杠中的横牌)= 同档旋转 90°,M 横置即 40×28;
- 牌面结构:1px `Tile.Edge` 描边 + `Radius.Tile` + `Shadow.Tile` + 居中墨色字符;
- 状态表达见下表(全部"文字角标 + 描边 + 图标"三重冗余,不只靠颜色)。

| 状态 | 视觉 |
|---|---|
| 普通 | 如上 |
| 悬停 | `Tile.Face.Hover` + 上移 2px |
| 选中 | 品牌绿 2px 描边 + 上移 4px |
| 推荐 | 品牌绿 2px 描边 + 右上"荐"角标(绿底白字) |
| 危险 | 危险红 2px 描边 + 右上"险"角标(红底白字) |
| 癞子 | 左上"癞"角标(紫底白字) |
| 皮 | 左上"皮"角标(蓝底白字) |
| 红中杠 | 左上"杠"角标(朱砂底白字) |
| 低置信度 | 琥珀 2px 虚线描边 + 右上"?"角标(琥珀底深字) |
| 不可打出 | `Tile.Face.Dim` + 不透明度 60%(如癞子在出牌候选中) |

## 6. 动效 Token

| Token 键 | 值 | 用途 |
|---|---|---|
| `Motion.Micro` | 120ms | 悬停、按下反馈 |
| `Motion.Standard` | 200ms | 卡片展开、Tab 切换、牌移动 |
| `Motion.Panel` | 280ms | 详细策略面板滑入/滑出 |
| `Motion.Ease.Out` | CubicEase EaseOut | 进入 |
| `Motion.Ease.InOut` | CubicEase EaseInOut | 退出/收起 |
| 自动收起延迟 | 默认 6s(设置可调 3–15s) | 紧凑建议卡 |

约束:错误/异常状态**静态呈现**,不使用循环闪烁或循环动画;加载优先使用静态骨架屏,其次才是 1.2s 线性 spinner;所有动效遵循系统"减少动画"设置(关闭时全部降为 0ms 直接切换)。

## 7. 密度模式

| 项 | 舒适(默认) | 紧凑 |
|---|---|---|
| 页面外边距 | 24 | 16 |
| 卡片内边距 | 16 | 12 |
| 列表行高 | 40 | 32 |
| 侧导航宽 | 208 | 176 |
| 表格/诊断区字号 | Body 13 | Caption+1 = 12 |
| 适用 | 默认、首次使用 | 诊断详情、复盘高密度视图、用户手动切换 |

密度只改间距与表格字号,不改变颜色、字号层级关系与组件结构;悬浮助手固定使用自己的密度(不受主窗口密度开关影响)。

## 8. 图标

- 风格:1.5px 描边线性图标,圆角端点,16px 网格(导航用 20px);
- 来源:自建最小集(约 30 枚),原创绘制,不引入第三方游戏/棋牌素材;
- 必备语义图标:监控中、已暂停、识别中、低置信度(三角叹号)、错误(圆叉)、窗口丢失、API 超时、隐私(盾牌/眼睛)、癞、皮、杠、风险低/中/高(盾+刻度)、快捷键(键盘键帽)。

## 9. 可访问性基线

- 正文文本对比度 ≥ 4.5:1,大文本/图标 ≥ 3:1(上表配色已按此校验:Text.Secondary `#B7BAB2` 对 Bg.Card `#23272E` ≈ 8.4:1);
- 风险/状态永远"文字 + 图标 + 颜色"三重表达;
- 全键盘可达:导航、牌选择、纠错、收起均可用键盘完成,焦点环 `Brush.Border.Focus` 2px;
- 支持 100%/125%/150% DPI 缩放,布局按 dp 网格自适应(见各稿"最低尺寸"标注);
- 色盲校验:推荐(绿)与危险(红)同时以"荐/险"角标文字区分。
