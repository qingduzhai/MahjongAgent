# 08 首次启动 · 窗口选择 · 首次标定 · 识别纠错 · 窗口档案(高保真稿)

> 对应提示词 v2 第七节 1–5 与交付项 8。本文件覆盖"从第一次打开到系统开始可靠工作"的完整链路与长期档案管理。
> **v1.1 修订**(按 `review-codex.md`):P1-6 隐私口径拆为捕获/上传/短期缓冲/长期保存/训练贡献五类;P1-7 离线仍可保存本地档案候选;P0-1 标定识别出的规则项仅写入本档案,不作全局结论。
> **v1.2 修订**(按 `review-codex-round-2.md` R2-P0-2):首次配置多模态服务覆盖 OpenAI-Compatible 参数(预设/Base URL/Completions Path/模型 ID/认证/结构化输出/图片 detail);测试连接展示已验证能力与失败分类;换 Key 事务式;本地 None 认证免 API Key。
> **v1.3 修订**(第三轮审核):Provider 地址契约对齐后端——Base URL 必须以 `/` 结尾、Completions Path 不允许 `/` 开头;自定义 Header 补齐名称/前缀/附加 Header 输入;「自动探测」改为 UI 动作,持久化仅 JsonSchema/JsonObject,降级须合成图探测+本地校验并显示「结构化输出降级」;能力探测保存为 LastProbe,配置变化即失效。

## 6. 状态速查(本文件五页共用要求)

空 / 加载(骨架屏)/ 正常 / 低置信度 / API Key 无效 / API 超时 / 无网络(仅云端识别与验证不可用,按钮禁用+原因)/ 权限不足 / 操作确认 均按 06 号文件 §4 的同一套模式呈现。**无网络时的纠错弹窗**(P1-7):`仅修正本局` 与 `同时改进窗口档案` 均可用——修正本局是本地补偿事件,改进档案是本地保存裁剪样本并写入 candidate 记忆,都不需要网络;仅"立即调用云端模型重新识别/验证"类操作禁用并注明原因。
