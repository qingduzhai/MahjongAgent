> 对应提示词 v2 第六节 1 与 3。主窗口基准 1280×800,最低 1024×640。仪表盘定位:**30 秒判断系统是否健康、正在监控谁、这局花了多少钱、记忆是否在良性积累**;建议摘要不抢悬浮助手定位。
> **v1.1 修订**(按 `review-codex.md`):P0-4 导航新增"记忆与学习"一级页面并加摘要卡;P1-5 拆分捕获采样与多模态识别两套指标、补全延迟链;P1-8 数据保留口径一致化;P0-2 建议摘要改用推荐等级。

## 3. 卡片与摘要条规格

统一:卡片 316×156(3×3,列距 16),`Bg.Card` + `Radius.Card` + `Shadow.Card`,内边距 16;结构 = 标题(Caption `Text.Secondary`)+ 主指标(Display 26 Font.Numeric 或 Body.Strong)+ 辅助行 + 状态行(图标+文字)。

| 卡片 | 内容与口径(P1-5:捕获采样与多模态识别严格分开) |
|---|---|
| 捕获与变化检测 | 捕获采样率(画面源 fps)、变化检测命中率、稳定画面事件数;状态:●正常 / ▲帧丢失 / ✕捕获失败(跳窗口选择)。**不暗示"每帧都调用模型"** |
| 多模态识别 | 最近一次识别时间、工作模式(observe/calibrate/recover)、本局**多模态调用次数**、估算成本(注"估算") |
| 延迟链 | 画面稳定→GameEvent 延迟、GameEvent→建议延迟、P95 端到端;两段分列,可定位瓶颈在识别还是策略 |
| 事件同步 | 最新事件 ID、积压数、校验结论 |
| 识别置信度趋势 | 近 20 次迷你折线(Brand 描边,低于阈值段 Warning)+ 当前值/最低值 |
| 状态矛盾 | 待处理数;>0 时 Warning 边框 + [去处理] 跳当前牌局页 |
| 最近错误 | 级别图标 + 一句话 + 相对时间 + [查看日志] |
| 本地数据与保留(P1-8) | 档案数与总占用;保留口径:GameEvent/DecisionSnapshot/纠错 90 天,confirmed 记忆长期(不随牌局日志过期);样本数带 🛈 Tooltip(仅裁剪牌区,可随时删除) |
| 记忆与学习(P0-4) | confirmed / candidate 计数、待审核数(>0 时 Warning)、最近整合时间;[打开] 跳"记忆与学习"页(见 14 号文件) |

**当前建议摘要条**(全宽 48px,`Bg.Card`):建议牌 Tile.M + `首选` + 推荐等级 chip + 向听/进张一行;固定脚注 `摘要,实时建议以悬浮助手为准`;动作仅 [打开当前牌局]——**不抢悬浮助手定位**,不在此提供逐巡操作。

**诊断折叠区**(提示词六.3):窗口身份(进程·类名·尺寸·DPI)、Provider+模型+Schema、**版本行(策略/规则/提示模板/模型)**、最近识别请求耗时序列、Observation 候选/已接受/已拒绝及原因、状态校验清单、[立即重新同步](二次确认)。普通用户默认只看摘要。

## 4. 状态覆盖

| 状态 | 呈现 |
|---|---|
| 空(未选窗口) | 状态条 `未监控`;内容区空态插画(原创线稿牌桌)+ `选择目标窗口` 主按钮 + 3 步引导 |
| 加载 | 卡片与摘要条骨架屏(占位块 30% 透明度,无动画) |
| 正常监控 | 如上 |
| 低置信度 | 状态条档案 chip 旁 `▲ 置信度偏低`;趋势卡标黄;摘要条注明不确定项与影响范围(P1-1) |
| API Key 无效 | 状态条 API 项 Danger `API Key 无效`;顶部 56px Danger 横幅 + [去设置] |
| API 超时/无网络 | 状态条 API 项 Warning;延迟链卡主指标 `超时重试中`;横幅可关闭 |
| 目标窗口丢失 | 状态条监控项 Danger `窗口丢失`;捕获卡 ✕;摘要条灰显 |
| 布局漂移 | 档案 chip Warning `档案可能过期`;诊断区首行提示重新标定 |
| 状态矛盾 | 矛盾卡 Warning 边框 + 计数 + [去处理] |
| 暂停 | 状态条服务项 `❚❚ 已暂停`(全窗口降饱和 15%);按钮变 ▶恢复 |
| 牌局结束 | 阶段 chip `本局已结束`;摘要条换为 `复盘已生成 [查看复盘]`;记忆卡显示 `本局已进入后台整合队列` |

## 5. 交互规格

- 卡片固定网格不可拖拽;hover 仅 `Border.Strong` 描边反馈;
- `重新同步` 二次确认(丢弃未确认观察);跳转按钮带筛选上下文;
- 关闭主窗口 = 最小化到托盘(首次关闭气泡提示 `监控将在后台继续`);托盘菜单:打开仪表盘 / 暂停|恢复 / 呼出悬浮助手(显示当前配置的热键)/ 退出(二次确认,退出会停止监控)。
