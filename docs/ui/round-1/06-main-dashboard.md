# 06 主窗口 · 仪表盘首页(高保真稿)

> 对应提示词 v2 第六节 1 与 3。主窗口基准 1280×800,最低 1024×640。仪表盘定位:**30 秒判断系统是否健康、正在监控谁、这局花了多少钱**;建议摘要不抢悬浮助手定位。

## 3. 卡片规格(9 张运维卡 + 诊断折叠区)

统一:316×176(3 列 ×3 行,列间距 16),`Brush.Bg.Card` + `Radius.Card` + `Shadow.Card`,内边距 16;结构 = 标题(Caption `Text.Secondary`)+ 主指标(Display 26 Font.Numeric 或 Body.Strong)+ 两行辅助(Caption `Text.Tertiary`)+ 状态行(图标+文字)。

| 卡片 | 主指标 | 辅助与状态 |
|---|---|---|
| 捕获帧状态 | `30fps · 稳定` | 变化检测命中率 12%;状态:●正常 / ▲帧丢失 / ✕捕获失败(跳窗口选择) |
| 最近视觉识别 | `2 秒前` | 工作模式(observe/calibrate/recover);识别区域数 |
| 多模态延迟与成本 | `1.2s` | P95 2.4s;本局调用 17 次;估算成本 ¥0.34(Font.Numeric,成本旁注"估算") |
| 事件同步 | `#58` | 最新事件 ID、积压数、校验结论 |
| 识别置信度趋势 | `96%` | 近 20 次迷你折线(Stroke `Brush.Brand.Default`,低于阈值段改 Warning)+ 最低值 |
| 状态矛盾 | `0` | 待处理数;>0 时整卡 Warning 边框 + [去处理] 按钮跳当前牌局页 |
| 最近错误 | `无(24h)` | 有则:级别图标 + 一句话 + 相对时间 + [查看日志] |
| 本地数据 | `42MB` | 档案数、事件日志、视觉样本数(样本数带 🛈 Tooltip:仅裁剪牌区,可随时删除) |
| 当前建议摘要 | `打九条` | 向听/进张一行;固定脚注 `摘要 · 实时建议见悬浮助手`,按钮仅"打开当前牌局"——**不抢悬浮助手定位**,不在此提供逐巡操作建议 |

诊断折叠区(提示词六.3):默认仅一行摘要 `▸ 诊断详情:窗口身份 / DPI·帧率 / Provider / 候选与校验 / 重新同步`;展开后等宽字体表格呈现:`窗口身份(进程·类名·尺寸·DPI·帧率)`、`变化检测命中率`、`Provider+模型+Schema 版本`、`最近请求耗时序列`、`Observation 候选/已接受/已拒绝及原因`、`状态校验结果清单`、`[立即重新同步]` 按钮(二次确认)。

## 4. 状态覆盖

| 状态 | 呈现 |
|---|---|
| 空(未选窗口) | 状态条显示 `未监控`;卡片区替换为空态插画(原创线稿牌桌)+ `选择目标窗口` 主按钮 + 3 步引导列表(选择窗口→自动标定→开始监控) |
| 加载 | 卡片骨架屏(占位块 `Brush.Bg.Elevated` 30% 透明度,无动画) |
| 正常监控 | 如上 |
| 低置信度 | 状态条档案 chip 旁加 `▲ 置信度偏低`;趋势卡标黄;建议摘要卡注明"倾向性建议" |
| API Key 无效 | 状态条 API 项 Danger `API Key 无效`;仪表盘顶部插 56px Danger 横幅 + [去设置] |
| API 超时/无网络 | 状态条 API 项 Warning;延迟卡主指标改 `超时重试中`;横幅可关闭 |
| 目标窗口丢失 | 状态条监控项 Danger `窗口丢失`;捕获卡 ✕;建议摘要卡灰显 |
| 布局漂移 | 档案 chip 变 Warning `档案可能过期`;诊断区首行提示"检测到布局变化,建议重新标定" |
| 状态矛盾 | 矛盾卡 Warning 边框 + 计数 + [去处理] |
| 暂停 | 状态条服务项 `❚❚ 已暂停`(全窗口降饱和度 15% 提示);按钮变 ▶恢复 |
| 牌局结束 | 阶段 chip 变 `本局已结束`;建议摘要卡换为"复盘已生成 [查看复盘]" |

## 5. 交互规格

- 卡片不可拖拽(固定网格,信息架构稳定优先);hover 仅 `Border.Strong` 描边反馈;
- `重新同步` 二次确认(会丢弃未确认观察);所有跳转按钮直达对应页面并带上筛选上下文;
- 关闭主窗口 = 最小化到托盘(首次关闭时气泡提示一次"监控将在后台继续");托盘菜单:打开仪表盘 / 暂停|恢复 / 呼出悬浮助手 Alt+M / 退出(二次确认,退出会停止监控)。
