# 03 悬浮助手 · 待机胶囊(高保真稿)

> 对应提示词 v2 第五节 1。悬浮助手第一优先级。所有悬浮层共用:`Brush.Bg.Overlay`(95% 不透明)+ `Radius.Panel`(胶囊为 `Radius.Capsule`)+ `Shadow.Overlay` + 1px `Brush.Border.Subtle`;置顶、不激活、默认鼠标穿透。

## 1. 定位与职责

待机胶囊是悬浮助手的常态形态:**证明系统在健康运行**,除此之外尽量没有存在感。

- 尺寸:**180×40**(悬停展开态 248×40);
- 吸附目标游戏窗口边缘,默认位于窗口**右上角内侧**(避开多数麻将平台的操作按钮区),可拖动改附四边任意位置,位置记入 WindowProfile;
- 不遮挡游戏手牌区与操作按钮区;不抢焦点;默认鼠标穿透(指针事件直达游戏),需要交互时按住 `Alt` 或先按全局快捷键进入"可交互态"。

## 2. 结构分解(正常态,180×40)

```text
x=0                                                          x=180
┌──────────────────────────────────────────────┐ y=0
│  ●   监控中 · 第6巡 · 识别正常           ⋮⋮  │ y=40
└──────────────────────────────────────────────┘
 └┬─┘ └──────────────┬──────────────┘       └┬─┘
  状态点            三段式状态文本          拖动柄(仅可交互态可见)
```

| 元素 | 位置/尺寸 | 规格 |
|---|---|---|
| 容器 | 180×40 | `Brush.Bg.Overlay`,`Radius.Capsule`,1px `Brush.Border.Subtle`,`Shadow.Overlay` |
| 状态点 | x12 y16,8×8 圆 | 颜色随状态(见第 3 节),**同时**在文本中体现,非唯一表达 |
| 状态文本 | x28 起,垂直居中 | Caption 11/16,`Brush.Text.Primary`;三段以 `·` 分隔:连接状态 / 巡目 / 识别健康度 |
| 拖动柄 | 右缘 x164,宽 12 | 六点竖纹,`Brush.Text.Tertiary`;仅可交互态显示 |

悬停展开态(248×40,仅可交互态下悬停触发,200ms 向右扩展):追加三段操作区——

```text
┌────────────────────────────────────────────────────────────┐
│ ● 监控中 · 第6巡 · 识别正常     [⏸暂停] [⌨Alt+M] [—隐藏] │
└────────────────────────────────────────────────────────────┘
```

- `[⏸暂停]`:切换暂停/恢复(Caption + 图标);
- `[⌨Alt+M]`:快捷键提示 chip(`Brush.Bg.Elevated` 底,`Radius.Chip`,Caption 11),提示"呼出详细策略";
- `[—隐藏]`:收起为迷你点(24×24,仅状态点),点击迷你点恢复胶囊。

## 3. 全部状态稿(提示词第五节 4 要求的悬浮异常态在此与紧凑卡间分配:胶囊层呈现"系统级"状态)

### 3.1 监控中(正常)

```text
┌──────────────────────────────────────────────┐
│  ●  监控中 · 第6巡 · 识别正常                │
└──────────────────────────────────────────────┘
状态点:Brush.Brand.Default;边框:Border.Subtle
```

### 3.2 识别中(画面变化,正在多模态解析)

```text
┌──────────────────────────────────────────────┐
│  ◐  识别中… · 第6巡                          │
└──────────────────────────────────────────────┘
状态点:Brush.Info.Default;文本"识别中…"替代健康度段;无循环闪烁,静态呈现(进度由紧凑卡/主窗口承担)
```

### 3.3 低置信度(本局存在未确认观察)

```text
┌──────────────────────────────────────────────┐
│  ▲  监控中 · 第6巡 · 置信度偏低              │
└──────────────────────────────────────────────┘
状态点变为空心三角图标+Brush.Warning.Default;文本"置信度偏低"Brush.Warning.Default
边框:1px Brush.Warning.Default(40%);不闪烁
```

### 3.4 正在恢复状态(状态矛盾/布局漂移,recover 模式)

```text
┌──────────────────────────────────────────────┐
│  ◐  恢复理解中 · 重新识别牌桌                │
└──────────────────────────────────────────────┘
图标:Info;文本:Brush.Text.Secondary;期间紧凑卡不出现
```

### 3.5 API 超时

```text
┌──────────────────────────────────────────────┐
│  ▲  建议延迟 · 识别正常 · 第6巡              │
└──────────────────────────────────────────────┘
图标:Warning;"建议延迟"替代健康度段;Tooltip(可交互态悬停):最近请求超时,正在重试
```

### 3.6 目标窗口丢失

```text
┌──────────────────────────────────────────────┐
│  ✕  窗口丢失 · 点击重新选择                  │
└──────────────────────────────────────────────┘
图标:Danger;文本:Brush.Danger.Default;边框:1px Brush.Danger.Default(40%)
失去吸附目标后胶囊固定在原屏幕位置;点击(可交互态)打开主窗口"窗口选择"
```

### 3.7 已暂停

```text
┌──────────────────────────────────────────────┐
│  ❚❚  已暂停 · 第6巡 · 按 Alt+M 恢复          │
└──────────────────────────────────────────────┘
图标+文本:Brush.Text.Tertiary;容器不透明度降至70%;暂停期间不弹紧凑卡
```

### 3.8 信息不足(局初/刚恢复,暂不提供强建议)

```text
┌──────────────────────────────────────────────┐
│  ●  监控中 · 第1巡 · 观察积累中              │
└──────────────────────────────────────────────┘
状态点:Brush.Brand.Default;"观察积累中"替代健康度段,Text.Secondary
```

## 4. 交互规格

| 行为 | 规格 |
|---|---|
| 鼠标穿透 | 默认开启(WS_EX_TRANSPARENT);按住 `Alt` 或快捷键呼出后进入可交互态,指针悬停即恢复穿透的视觉提示(拖动柄淡出) |
| 拖动 | 可交互态拖拖动柄;靠近窗口四边 24px 内触发吸附引导线;松手记录相对锚点 |
| 单击 | 可交互态单击 → 展开为紧凑建议卡(若有当前建议)或显示"暂无建议,等待你的回合"空态卡 |
| 右键 | 上下文菜单:暂停监控 / 隐藏提示 / 打开仪表盘 / 重新同步 / 退出 |
| 目标窗口移动/缩放/最小化 | 跟随锚点重定位;最小化时降级为迷你点贴任务栏上方原位置;窗口关闭 → 3.6 窗口丢失态 |
| 多显示器 | 跟随目标窗口所在显示器;DPI 变化按 Per-Monitor V2 重算 |

## 6. WPF 映射要点(详见 12 号文件)

`Border(CornerRadius=20) > Grid[3列]`:Ellipse + TextBlock + 拖动柄 Path;窗口 `AllowsTransparency=True`、`WindowStyle=None`、`Topmost=True`、`ShowActivated=False`,Win32 扩展样式 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`,穿透态加 `WS_EX_TRANSPARENT`。
