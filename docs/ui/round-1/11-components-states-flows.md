## 1. 组件清单与状态矩阵

### 1.1 按钮 `Btn`(高 32,`Radius.Control`,Body.Strong 13,左右 padding 16)

| 变体 | 默认 | 悬停 | 按下 | 禁用 | 加载 | 错误 |
|---|---|---|---|---|---|---|
| Primary(品牌实心) | `Brand.Default` 底 + `Text.OnAccent` | `Brand.Hover` | `Brand.Pressed` | 底 40% 透明 + `Text.Disabled` | 文字前 16px spinner + `处理中…` + 禁点 | —(错误走横幅/内联) |
| Secondary(描边) | `Border.Default` 描边 + 透明底 | `Bg.Elevated` 底 | 底加深 + 内缩 1px | 同 Primary 规则 | 同上 | — |
| Danger(实心) | `Danger.Default` 底 | `Danger.Hover` | `Danger.Pressed` | 同上 | 同上 | — |
| Ghost(文字) | `Text.Link` | `Bg.Elevated` 底 | 底加深 | `Text.Disabled` | — | — |

焦点:全部变体外环 2px `Border.Focus`。删除/回滚/重新同步等高危动作必须经确认模态。

### 1.2 输入框 `Input`(高 32,`Bg.Input` 底,`Radius.Control`,1px `Border.Default`)

默认 / 悬停(`Border.Strong`)/ 聚焦(`Border.Focus` 外环)/ 禁用(40% 透明)/ 占位(`Text.Tertiary`)/ 错误(`Danger.Default` 描边 + 下方 Caption 错误文字 + 三角图标)/ 加载(右侧 spinner)。API Key 框为密码掩码样式;"问 Agent"追问框复用本组件(仅 InteractiveOverlay 渲染)。

### 1.3 卡片 `Card`(`Bg.Card`,`Radius.Card`,`Shadow.Card`,1px `Border.Subtle`,padding 16/紧凑 12)

默认 / 悬停(可选,`Border.Strong`)/ 选中(1px `Brand.Default` 描边)/ 警示(1px Warning 40%)/ 危险(1px Danger 40%)/ 加载(骨架块)/ 禁用(60% 透明 + 原因条)。

### 1.4 徽标/Chip(高 20,`Radius.Chip`,Micro 10)

状态点 + 文字;变体:Brand / Success / Warning / Danger / Info / Neutral;示例:`本档案已确认✓` `待确认⚠` `来源冲突⚡` `杠×1` `荐` `险` `信息不足` `candidate` `confirmed` `superseded`。

### 1.5 导航项 `NavItem`(高 40,20px 图标 + Body 13)

默认(`Text.Secondary`)/ 悬停(`Bg.Elevated`)/ 选中(左 3px 品牌条 + `Bg.Elevated` + `Text.Primary`)/ 带徽标(圆点或计数,如"记忆与学习"待审核数)/ 禁用。

### 1.6 麻将牌 `Tile`(三档尺寸与状态见 02 号文件 §5)

34 种 canonical 牌面(27 数牌 + 7 字牌)齐备;癞/皮/杠为**局内角色叠加层**(角标),不是牌面身份;可选中的牌支持 `←/→` + `Enter`;低置信度牌 `Enter` 直接打开纠错弹窗。**TileView 与交互层不含任何规则逻辑**——"某牌是否可打出"由 ViewModel 数据决定,不由控件判断(P0-1)。

### 1.7 列表行 `Row`(高 40/紧凑 32)

默认 / 悬停(`Bg.Elevated`)/ 选中(品牌 1px 描边内嵌)/ 分隔线 `Divider` / 行内操作悬停才显 / 加载骨架。

### 1.8 弹窗 `Dialog`(`Bg.Dialog` + Scrim,`Radius.Panel`,`Shadow.Dialog`,宽 480–560)

标题栏 + 内容 + 按钮区(右对齐);`Esc` 关闭(高危确认弹窗 `Esc` = 取消);错误内容用内联 Danger 条。

### 1.9 浮层/横幅/Tooltip

- 横幅 `Banner`(页面顶部 48–56,Info/Warning/Danger,图标+文字+动作+可关闭);
- Tooltip(高 28+padding,Caption,`Bg.Elevated`,延迟 400ms;**悬浮层 Tooltip 仅 InteractiveOverlay**,PassiveOverlay 穿透状态下不存在悬停);
- 进度:确定进度用 2–4px 细条;不确定进度用骨架屏;错误/异常静态呈现,无循环动画。

## 2. 悬浮助手状态机(P0-3,双模式)

```text
┌────────────────────── PassiveOverlay(默认) ───────────────────────┐
│ TOOLWINDOW|NOACTIVATE|TRANSPARENT · ShowActivated=False           │
│ 鼠标穿透 · 只显示 · 无键盘焦点 · 仅响应全局热键                    │
│                                                                    │
│   ┌──────────┐  轮到我(AlertPolicy)  ┌──────────┐                 │
│   │ 待机胶囊  │ ───────────────────▶ │ 紧凑建议卡│(6s 自动收起/  │
│   └──────────┘ ◀─────────────────── └──────────┘  出牌即收)      │
│        ▲              出牌完成/超时                                │
└────────┼───────────────────────────────────────────────────────────┘
         │ 全局热键(可配置,Mock 占位 Alt+M)
         ▼
┌────────────────────── InteractiveOverlay ─────────────────────────┐
│ 保留 TOOLWINDOW;摘除 TRANSPARENT 与 NOACTIVATE(R2-P0-1)          │
│ 记录前台 HWND · 显式激活 · 焦点进控件 · 鼠标/键盘/追问/纠错        │
│                                                                    │
│   待机胶囊(悬停展开/可拖动/右键菜单) ⇄ 紧凑卡 ⇄ 详细策略面板     │
│                                                                    │
│   退出:Esc / 再按热键 / 显式关闭 / Deactivated(焦点转到外部    │
│   应用;自有窗口与输入法候选窗除外,见 12 §3) / 无操作 30s       │
│   (可配;输入法组合·追问发送·纠错弹窗期间暂停) / 窗口丢失        │
│   → 清焦点 → 恢复 NOACTIVATE+TRANSPARENT → 回 PassiveOverlay;    │
│   前台恢复分路径:仅 Esc/热键/超时/显式关闭恢复此前前台窗口,    │
│   Deactivated 路径不恢复,避免抢回焦点(v1.3)                    │
└────────────────────────────────────────────────────────────────────┘

异常分支(两种模式下均可进入,恢复后回胶囊):
  识别中 / 低置信度 / 恢复中 / API超时 / 窗口丢失 / 已暂停 / 信息不足
  —— 异常态只改内容与边框,不改变尺寸、不闪烁、不遮挡操作区;
     Esc 与方向键只在 InteractiveOverlay 获得焦点后有效;
     "点击面板外"以 Deactivated 判定,不使用覆盖游戏的透明命中层;
     Deactivated 经自有窗口/输入法作用域过滤,且该路径不恢复前台(v1.3)。
```

## 3. 完整交互流程(提示词第八节,局内零人工录入)

```text
首次启动
  → ① 引导:能力边界 → ② 配置API(测试连接) → ③ 隐私选择(五分类)
  → 选择目标窗口(缩略图卡片,匹配档案或创建)
  → 首次自动标定(区域确认/手动调整/暂时不确定;规则项仅写入本档案)
  → 创建 WindowProfile(命名,保存)
  → 后台监控启动(悬浮胶囊出现,PassiveOverlay)
  → 主窗口可关闭到托盘(首次关闭气泡提示"后台继续")
  → 牌局变化:变化检测 → observe → 校验 → GameEvent → 状态更新(全部自动)
  → 轮到用户:紧凑建议卡自动弹出(首选;6s 收起,确认出牌即收,10s 兜底)
  → 全局热键:进入 InteractiveOverlay → 详细策略面板(为什么/备选/风险/参考经验/问 Agent)
  → 低置信度:策略敏感性分析(全部自动,见下)
      ├─ 关键不确定(影响合法动作/向听/癞子身份/首选弃牌)→ 暂停建议 + 纠错入口
      └─ 非关键不确定 → 保留建议 + 标注影响范围(进张给区间)
  → 纠错:仅修正本局 或 写入本档案 candidate(离线可用;不阻塞建议流)
  → 牌局结束:自动生成复盘;Episode 进入后台整合队列
  → 记忆沉淀: candidate →(规则验证/策略回放/固定评测集)→ confirmed/rejected;
      confirmed 长期保留;主窗口"记忆与学习"可检索、审核、回滚、删除
  → 档案沉淀:confirmed 视觉样本写入 WindowProfile 新版本,下次同窗口自动加载
```

主流程内**没有**"录入牌面""点击开始分析"步骤;局内动作只有"看建议"和"可选的纠错/追问"。

## 4. 全局快捷键表(全部可配置;默认值仅为 Mock 占位,review 决定 #11)

| 快捷键(Mock 默认) | 作用 | 可用范围 |
|---|---|---|
| `Alt+M` | 进入 InteractiveOverlay 并呼出详细策略(或先展开紧凑卡);再按收起 | 全局 |
| `Alt+P` | 暂停/恢复监控 | 全局 |
| `Esc` | 退出 InteractiveOverlay / 收起面板 / 关闭弹窗 | **仅 InteractiveOverlay 获得焦点后** |
| `←/→ ↑/↓` `Enter` | 牌与候选导航、确认 | 主窗口牌局页、纠错弹窗、InteractiveOverlay |
| `W` / `C` / `/` | 展开为什么 / 纠错 / 聚焦追问框 | 详细策略面板(InteractiveOverlay) |

不设计"按住修饰键进入交互态"(P0-3:Alt 是系统与游戏常用键,低级键盘钩子不作首版依赖)。
