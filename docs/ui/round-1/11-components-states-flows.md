# 11 组件状态与交互流程

> 对应提示词 v2 第八、九节与交付项 10。组件视觉全部引用 [02 号 Token](02-visual-direction-tokens.md);每组件覆盖:默认 / 悬停 / 按下 / 禁用 / 加载 / 错误(审核清单·工程交付)。

## 1. 组件清单与状态矩阵

### 1.1 按钮 `Btn`(高 32,`Radius.Control`,Body.Strong 13,左右 padding 16)

| 变体 | 默认 | 悬停 | 按下 | 禁用 | 加载 | 错误 |
|---|---|---|---|---|---|---|
| Primary(品牌实心) | `Brand.Default` 底 + `Text.OnAccent` | `Brand.Hover` | `Brand.Pressed` | 底 40% 透明 + `Text.Disabled` | 文字前 16px spinner + `处理中…` + 禁点 | —(按钮自身无错误态,错误走横幅/内联) |
| Secondary(描边) | `Border.Default` 描边 + `Text.Primary` 透明底 | `Bg.Elevated` 底 | 底加深 + 内缩 1px | 同 Primary 规则 | 同上 | — |
| Danger(实心) | `Danger.Default` 底 | `Danger.Hover` | `Danger.Pressed` | 同上 | 同上 | — |
| Ghost(文字) | `Text.Link` | `Bg.Elevated` 底 | 底加深 | `Text.Disabled` | — | — |

焦点:全部变体外环 2px `Border.Focus`(键盘导航可见)。删除/回滚/重新同步等 Danger/高危动作必须经确认模态。

### 1.2 输入框 `Input`(高 32,`Bg.Input` 底,`Radius.Control`,1px `Border.Default`)

默认 / 悬停(`Border.Strong`)/ 聚焦(`Border.Focus` 外环)/ 禁用(40% 透明)/ 占位(`Text.Tertiary`)/ 错误(`Danger.Default` 描边 + 下方 Caption 错误文字 + 三角图标)/ 加载(右侧 spinner,如"测试连接"中的 Key 框)。API Key 框为密码掩码样式。

### 1.3 卡片 `Card`(`Bg.Card`,`Radius.Card`,`Shadow.Card`,1px `Border.Subtle`,padding 16/紧凑 12)

默认 / 悬停(可选,`Border.Strong`,仅可点击卡片)/ 选中(1px `Brand.Default` 描边)/ 警示(1px Warning 40% 描边)/ 危险(1px Danger 40% 描边)/ 加载(骨架块 `Bg.Elevated` 30%)/ 禁用(整体 60% 透明 + 原因条)。

### 1.4 徽标/Chip(高 20,`Radius.Chip`,Micro 10)

状态点 + 文字;变体:Brand / Success / Warning / Danger / Info / Neutral(`Bg.Elevated`);示例:`已验证✓` `待确认⚠` `来源冲突⚡` `杠×1` `荐` `险` `信息不足`。

### 1.5 导航项 `NavItem`(高 40,20px 图标 + Body 13)

默认(`Text.Secondary`)/ 悬停(`Bg.Elevated`)/ 选中(左 3px 品牌条 + `Bg.Elevated` + `Text.Primary`)/ 带徽标(右侧圆点或计数)/ 禁用。

### 1.6 麻将牌 `Tile`(三档尺寸与 10 种状态见 02 号文件 §5)

补充行为:可选中的牌支持 `←/→` 移动焦点 + `Enter` 选中;不可打出牌(癞子)聚焦时 Tooltip 说明原因;低置信度牌 `Enter` 直接打开纠错弹窗。

### 1.7 列表行 `Row`(高 40/紧凑 32)

默认 / 悬停(`Bg.Elevated`)/ 选中(品牌 1px 描边内嵌)/ 分隔线 `Divider` / 行内操作按钮悬停才显(减少噪声)/ 加载骨架。

### 1.8 弹窗 `Dialog`(`Bg.Dialog` + Scrim,`Radius.Panel`,`Shadow.Dialog`,宽 480–560)

标题栏 + 内容 + 按钮区(右对齐,主按钮在最右);`Esc` 关闭(高危确认弹窗 `Esc` = 取消);错误内容用内联 Danger 条,不用 toast。

### 1.9 浮层/横幅/Tooltip

- 横幅 `Banner`(页面顶部 48–56,Info/Warning/Danger 三档,图标+文字+动作按钮+可关闭);
- Tooltip(高 28+padding,Caption,`Bg.Elevated`,延迟 400ms,悬浮层禁用 Tooltip 除非可交互态);
- 进度:确定进度用 2–4px 细条;不确定进度用骨架屏,**不用循环动画表达错误**。

## 2. 悬浮助手状态机(组件级)

```text
                 ┌────────────┐  轮到我/重要风险   ┌────────────┐
                 │  待机胶囊   │ ────────────────▶ │ 紧凑建议卡  │
                 │ (180×40)   │ ◀──────────────── │ (360×160)  │
                 └─────┬──────┘  出牌完成/6s超时   └─────┬──────┘
                       │  单击/Alt+M                     │ Alt+M/点击
                       │                                 ▼
                       │                          ┌────────────┐
                       └───────────────────────── │ 详细策略面板│
                             再按Alt+M/Esc收起    │ (420×520)  │
                                                  └────────────┘
异常分支(任何形态可进入,恢复后回到胶囊):
  识别中 / 低置信度 / 恢复中 / API超时 / 窗口丢失 / 已暂停 / 信息不足
  —— 异常态只改内容与边框,不改变尺寸、不闪烁、不遮挡操作区(03/04/05 号文件)
```

## 3. 完整交互流程(提示词第八节,局内零人工录入)

```text
首次启动
  → ① 引导:能力边界 → ② 配置API(测试连接) → ③ 隐私选择
  → 选择目标窗口(缩略图卡片,匹配档案或创建)
  → 首次自动标定(区域确认/手动调整/暂时不确定)
  → 创建 WindowProfile(命名,保存)
  → 后台监控启动(悬浮胶囊出现在窗口边缘)
  → 主窗口可关闭到托盘(首次关闭气泡提示"后台继续")
  → 牌局变化:变化检测 → observe → 校验 → GameEvent → 状态更新(全部自动)
  → 轮到用户:紧凑建议卡自动弹出(6s 自动收起,不抢焦点)
  → Alt+M:详细策略面板(为什么/备选/风险/不确定信息)
  → 低置信度:建议降级为倾向 + 可随时纠错(纠错不阻塞建议流)
  → 牌局结束:自动生成复盘(主窗口"牌局复盘"按巡回放)
  → 档案沉淀:confirmed 样本写入 WindowProfile 新版本,下次同窗口自动加载
```

主流程内**没有**"录入牌面""点击开始分析"步骤;用户唯一的局内动作是"看建议"和"可选的纠错"。

## 4. 全局快捷键表(默认值,可改)

| 快捷键 | 作用 | 可用范围 |
|---|---|---|
| `Alt+M` | 呼出/收起详细策略(或先展开紧凑卡) | 全局 |
| `Alt+P` | 暂停/恢复监控 | 全局 |
| 按住 `Alt` | 悬浮层进入可交互态 | 全局 |
| `Esc` | 收起卡片/面板/弹窗 | 悬浮层与主窗口 |
| `←/→ ↑/↓` `Enter` | 牌与候选导航、确认 | 主窗口牌局页、纠错弹窗 |
| `W` / `C` | 展开"为什么" / 进入纠错 | 详细策略面板 |
