### 2. 关键规格(P0-1)

- **牌集为全局常量**:标准 34 种 136 张(万/筒/条 1–9 + 东南西北中发白,不含花牌),由 Core `StandardTileSet` 定义,不属于规则变体;
- **规则值全部属于具体 RuleProfile**:页首明示档案名与版本;每条规则的"值"只对该档案生效,UI 不出现无作用域的规则断言;
- **状态三级 chip**:`✓ 本档案已确认`(Success,经本窗口标定/实测)/`⚠ 待确认`(Warning,有参考来源未实测)/`⚡ 来源冲突`(Danger,两参考资料矛盾);每行 Tooltip 显示来源与确认方式;
- **七对修正**:参考规则明确基础变体**不含**七对,显示为 `基础变体不含 · 参考`——不再列为"已验证大胡";大胡类型清单整体 `待确认`,逐条实测后单条晋升;
- **癞子处置修正**:按参考规则显示 `可打出/可作癞子杠`,状态 `待确认`;不再写死"癞子不可打出";
- **实测晋升边界**:`[标记本档案实测]` 只把规则标记为 **本 WindowProfile 已确认**;晋升全局"已验证"需要跨平台多样本验证,走规则版本发布流程(架构 3.4),**UI 不提供该操作**;
- **来源冲突视图**:冲突行点击展开两栏对照(百度百科 vs 知乎专栏,附链接与差异高亮),底部 `以目标平台实测为准` + `[标记本档案实测]`;
- 知识库条目带 `适用规则` 与 `可信度` 标记;知识用于解释,不替代计算(架构 5.9);
- 规则档案只读展示 + 变体切换下拉(经典红中赖子杠/开口翻/口口翻/七皮四癞…组合式);**UI 不提供规则编辑**。

### 2. 关键规格

- **Provider 配置(R2-P0-2;v1.3 对齐后端契约)**:预设(OpenAI/自定义兼容端点/本地端点)、Base URL(**必须以 `/` 结尾**,否则拼接丢失 `v1` 段)、Chat Completions Path(**相对路径,不允许 `/` 开头**,后端 `OpenAiCompatibleOptions.Validate` 直接拒绝,高级项)、视觉模型 ID(允许手工输入)、认证(Bearer/自定义 Header/None)——自定义 Header 须填 **Header 名称(默认 `api-key`)与 Key 前缀(可选,如 `Token `)**,并可添加附加 Header(`AdditionalHeaders`,适配 Azure 等特殊兼容端点)、结构化输出(**持久化仅 `JsonSchema`/`JsonObject`**;「自动探测」为 UI 动作:依次探测,成功才保存具体模式;仅 JsonObject 可用时经合成图探测+本地 Schema/牌数/规则校验允许降级,并显示「结构化输出降级」)、图片 detail(auto/low/high);非回环地址的 http 需显式允许(对齐 `AllowInsecureHttp`);`CredentialId` 内部生成,不向普通用户展示;本地 `None` 认证时不要求 API Key;
- **测试连接**:必须展示已验证能力——鉴权、图片输入、JsonSchema 或 JsonObject、实际模型、耗时、请求 ID;失败按 配置/鉴权/限流/服务/超时/协议/能力不符 分类显示(图标+文字,非仅颜色);探测结果保存为 **`LastProbe`**(含上次验证时间),打开设置页**不重复调用**;Base URL、Path、模型、认证、Key、输出模式任一变化**立即失效**,提示重新验证;
- **换 Key 事务式**:新 Key 测试成功后才替换旧凭据;失败或取消保留旧凭据;`Key 无效` Danger 文字 + 横幅联动(06 号文件 §4);
- **快捷键全部可配置**(review 决定 #11):键帽样式录入框,冲突检测;`Alt+M`/`Alt+P` 仅为 Mock 默认;无"按住修饰键交互"项;
- 悬浮层吸附位置默认 `窗口外侧右上`,实际锚点随 WindowProfile(决定 #2);`交互超时` 控制 InteractiveOverlay 无操作退回时间;
- 训练数据贡献为**独立开关、默认关**;`完整窗口画面:不持久化` 为固定只读项(P1-6 明确"不持久化"而非笼统"不保存";标定/恢复时的上传行为如实告知);
- **数据保留一致化(P1-8)**:GameEvent、DecisionSnapshot、纠错记录默认 90 天(复盘可完整重建);聚合统计与 confirmed 记忆长期保留,不随牌局日志过期(决定 #12);`一键删除` 支持按档案/按时间段/全部,二次确认;
- `生成诊断包`:列出包含内容(日志、脱敏配置、统计;不含 Key、画面、昵称头像),确认后生成;
- 所有变更即时生效并显示 `已保存` Caption。

### 3. 状态覆盖

未配置 API(空态 + [去配置])/ 测试连接中(按钮加载态)/ Key 无效 / 无网络(云端相关按钮禁用+原因;本地设置与本地样本操作不受影响)/ 快捷键冲突 / 删除确认中 / 诊断包生成进度(可取消)。
