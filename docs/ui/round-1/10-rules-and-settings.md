### 2. 关键规格

- **状态三级 chip**(与架构"所有未验证规则标记来源和验证状态"对齐):`✓ 已验证`(Success)/`⚠ 待确认`(Warning)/`⚡ 来源冲突`(Danger);每行 Tooltip 显示来源与验证方式(实测/文档/推断);
- **来源冲突视图**:冲突行点击展开两栏对照(百度百科 vs 知乎专栏,各附链接与差异点高亮),底部 `以目标平台实测为准` 提示 + `[标记实测结果]`(用户实战确认后升级为已验证,写入档案审计日志);
- 知识库条目带 `适用规则` 与 `可信度` 标记;知识用于解释,不替代计算(架构 5.9);
- 规则档案为只读展示 + 变体切换下拉(经典红中赖子杠/开口翻/口口翻/七皮四癞…组合式);**UI 不提供规则编辑**——规则修改走配置/版本流程(架构 3.4 不允许自主学习修改规则)。

### 2. 关键规格

- API Key:仅显示掩码,`更换` 需先 `测试连接` 通过才保存;`Key 无效` 状态 Danger 文字 + 横幅联动(见 06 号文件 §4);
- 快捷键录入:键帽样式输入框,按键捕获,冲突检测(与系统/游戏常用键冲突时 Warning 文字提示);
- 训练数据贡献为**独立开关、默认关**(审核清单·长期记忆);`完整截图:不保存` 为固定项只读展示,不可更改(架构隐私约束);
- `生成诊断包`:列出包含内容(日志、配置脱敏版、最近事件统计;不含 Key、截图、昵称头像),用户确认后生成;
- 所有变更即时生效并显示 `已保存` Caption;危险操作(清理数据/删除样本)二次确认。
