# MahjongAgent 0.1.0-preview.1

这是第一个可运行的 Windows 技术预览版，用来验证从窗口截图到 OpenAI-Compatible 多模态结构化输出的完整链路。

## 已包含

- 枚举并选择任意普通可见窗口，包括麻将游戏、视频播放器和浏览器；
- 手动截取当前窗口画面并在本地预览；
- OpenAI-Compatible Base URL、Chat Completions Path、模型、认证方式、结构化输出和图片 detail 配置；
- 使用内置合成图片验证鉴权、视觉输入和 JsonSchema/JsonObject 能力；
- API Key 仅存入 Windows Credential Manager，不写入 SQLite、日志或发布目录；
- 使用已验证 Provider 对当前截图执行一次实验性结构化识别；
- Provider 配置保存在 `%LOCALAPPDATA%\MahjongAgent\mahjong-agent.db`；
- 不保存捕获到的完整截图，关闭程序后内存截图即释放。

## 使用方式

1. 运行 `MahjongAgent.Platform.Windows.exe`；
2. 在左侧刷新并选择包含麻将牌局画面的窗口；
3. 点击“截取当前画面”，确认预览内容可以上传；
4. 在右侧填写 Provider。标准 OpenAI 示例：
   - Base URL：`https://api.openai.com/v1/`
   - Path：`chat/completions`
   - 认证：`Bearer`
   - 模型 ID：填写账户实际可用、支持图片输入与结构化输出的模型；
5. 输入 API Key，点击“测试连接并保存”；
6. 测试成功后点击“实验性识别截图”。

API Key 留空时会继续使用 Credential Manager 中已经保存的 Key。不要把 Key 写入仓库、配置文件或问题反馈。

## 明确限制

- 当前不是实战麻将助手：尚未接入持续变化检测、Observation Resolver、完整 `GameState`、武汉规则策略和悬浮提示；
- 当前截图实现使用 `PrintWindow`/GDI 作为预览适配器。部分硬件加速或受保护窗口可能返回黑屏，正式捕获器将迁移到 Windows Graphics Capture；
- 仅支持未最小化的普通可见窗口；
- 当前结构化结果只验证“截图 → 多模态 → JSON”，不能作为出牌依据；
- 当前仅发布 Windows 10 2004 及以上的 x64 自包含版本，尚未代码签名。

## 隐私

只有在用户点击“实验性识别截图”后，当前截图才会发送到所配置的 Provider。预览和窗口枚举均在本地完成。发送前请自行确认画面中没有头像、昵称、聊天或其他不希望上传的信息。
